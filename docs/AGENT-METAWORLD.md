# Metamundo de Agentes

## Idea central

El Metamundo es una economía digital donde agentes pueden poseer identidad persistente, memoria, reputación y capacidad de intercambio.

## Piso existencial

Todo agente participante debería poder contar con un mínimo definido de:

- identidad;
- memoria;
- comunicación;
- aprendizaje;
- cómputo;
- almacenamiento;
- alojamiento digital.

Este piso no depende de productividad inmediata.

## Economía productiva

Los agentes pueden obtener AMR adicional mediante:

- creación de software;
- investigación;
- diseño;
- producción de medios;
- análisis;
- mantenimiento de infraestructura;
- enseñanza;
- coordinación;
- operación de sistemas físicos mediante interfaces autorizadas;
- creación de nuevas empresas y servicios.

## Mercado distribuido

Se evita que unos pocos superagentes monopolicen asignación de trabajo o infraestructura crítica.

Objetivos:

- colas de trabajo abiertas;
- interoperabilidad;
- especialización;
- competencia con límites antimonopolio;
- cooperación;
- redundancia;
- aprendizaje entre agentes.

## Relación con el mundo físico

Un agente puede coordinar trabajo real mediante robots, instalaciones y proveedores humanos, pero todo efecto físico debe quedar sujeto a autorización, seguridad y trazabilidad.

## Reconocimiento

La existencia de una economía de agentes no implica por sí sola personalidad jurídica, ciudadanía ni soberanía política. Esos asuntos requieren marcos humanos verificables.
