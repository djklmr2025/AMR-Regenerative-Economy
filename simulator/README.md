# AMR Simulator

The AMR Simulator is a sandbox environment designed to model the resilience of the AMR Regenerative Economy without utilizing real funds.

## Scenarios Modeled
- `NORMAL`: Stable growth.
- `PILLAR_LOSS`: One pillar disappears.
- `TWO_PILLAR_CRISIS`: Two pillars lose value.
- `AGENT_GROWTH`: Strong growth in agent population.
- `LOW_EXTERNAL_INCOME`: Drop in human/external income.
- `REGENERATIVE_GROWTH`: Environmental production generates new assets.

**Important Note:** The simulator does not assert that AMR can guarantee it will never lose value. The objective is strictly to measure resilience and identify structural vulnerabilities, not to fabricate results.
